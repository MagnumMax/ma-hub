# README.md — эталон

Корень репо. **Для людей** (GitHub, новый человек, вы через месяц). Не инструкция агенту и не копия `standards/`.

Заполнять по факту продукта. Пустой раздел запрещён: либо текст, либо «не применимо: …».

## Обязательные разделы

| Раздел | Что должно быть | Объём |
|--------|-----------------|--------|
| **Название + суть** | Что это за продукт, кому он нужен, какую задачу закрывает | 1 короткий абзац |
| **Это не** | С чем не путать (другой продукт, «просто лендинг», внутренний прототип) | 1–3 пункта |
| **Кто пользуется** | Роли простым языком (менеджер, клиент, гость…) | список |
| **Как запустить** | Команды install / dev / test / build; какие env нужны (без паролей, ссылка на `.env.example`) | как есть в репо |
| **Где смотреть** | Ссылки на `AGENTS.md`, `DESIGN.md`; если есть боевой сайт — URL | 3–4 строки |
| **Статус** | Живой продукт / прототип / ещё не на проде | одна фраза |

Не писать сюда: pin хаба, пути релиза, токены дизайна, карту для ИИ.

````md
# <Имя продукта>

<Абзац: что это, для кого, какую задачу закрывает.>

## Это не
- …

## Кто пользуется
- **…** — …

## Как запустить

```bash
pnpm install
pnpm dev
```

Секреты — в `.env.local` (образец: `.env.example`). Пароли в README не писать.

## Где смотреть
- Как работать в репо: [AGENTS.md](./AGENTS.md)
- Как выглядит продукт: [DESIGN.md](./DESIGN.md)
- Боевой сайт: <URL или «ещё нет»>

## Статус
<живой / прототип / не на проде>
````
