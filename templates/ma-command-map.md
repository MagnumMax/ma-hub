# Карта команд `/MA-*`

Один источник «когда что», «что получите» и «что дальше». Команды ссылаются сюда, не копируют длинно.

## Когда какую запускать

| Нужно | Команда | Что получите | Это не |
|--------|---------|--------------|--------|
| Новая идея / фича | `/MA-idea-to-plan` | уточнения → подтверждённый план работ (без кода до «ок») | не выкат, не полная чистка продукта |
| Экран (админка, дашборд, лендинг) | `/MA-design-screen` | направление → после «ок» собранный проверяемый экран. Компас — стандарт хаба; анимации и прототипы — пакет Emil Kowalski, не общий «вкус» | не чистка кода, не прод |
| Сверить проект со стандартами хаба | `/MA-revise-project` | визитка + обязательные пути релиза + список, что подтянуть | не выкат |
| Глубокая чистка модулей, «убери ИИ-стиль» | `/MA-product-pass` | модули читаются людьми; контракты не ломаются молча | не релиз |
| Выкат на прод | `/MA-deploy` | одна **волна** (одна зона продукта) до прода: ревью кусков → срез жира → проверки → упаковка **только этой волны** → прод → обязательные пути. Смесь зон — несколько выкатов, стоп «какую волну сейчас» | не генеральная уборка; без списка путей не стартует; канон входа в `.env.local`; нет ролей — предложить создать + демо; созданное сверх демо убрать |
| SEO + видимость в ответах ИИ | `/MA-seo-geo-audit` | отчёт по поиску и ответам ИИ; правки сайта — после «чини» | не выкат |
| Список команд | `/MA-help` | этот перечень и ссылка на карту | — |

Типичный путь: **сверка** (если проект новый/отстал) → **идея** и/или **дизайн** → при шумном коде **полный прогон** → **выкат** → при необходимости **SEO**.

## Три упрощения (не смешивать)

| Где | Что | Зачем |
|-----|-----|--------|
| `/MA-idea-to-plan` | skill `ponytail` как **вкус** (не раздувать, не копировать текст) | фича не обрастает лишним |
| `/MA-product-pass` | `/simplify` + словарь **«убери ИИ-стиль»** | читать людям; контракты не ломать молча |
| `/MA-deploy` | `ponytail-review` **с автофиксом** по сегментам **волны**; таблица `net` / `Lean already` по каждому куску — иначе стоп. Смесь зон — несколько выкатов. Прочитать skill ≠ прогнать | быстрый срез жира перед продом |

Не подменять одно другим. Жёсткий словарь анти-ИИ — **только** полный прогон.

## Хвост после завершённой работы

После **готово** (не на паузе «жду ответ»): блок **«Следующие задачи»** — ровно 4 пункта с копируемыми промптами, по правилу пользователя.

Статус процесса — полный: *Сейчас / Что происходит / Ждём / Обычно занимает / Что от вас* (`standards/00-operating-model.md`).
