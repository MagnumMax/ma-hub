# Карта команд `/MA-*`

Один источник «когда что», «что получите» и «что дальше». Команды ссылаются сюда, не копируют длинно.

## Когда какую запускать

| Нужно | Команда | Что получите | Это не |
|--------|---------|--------------|--------|
| Новая идея / фича | `/MA-idea-to-plan` | уточнения → подтверждённый план работ (без кода до «ок») | не выкат, не полная чистка продукта |
| Экран (админка, дашборд, лендинг) | `/MA-design-screen` | направление → после «ок» собранный проверяемый экран. Компас — стандарт хаба; анимации и прототипы — пакет Emil Kowalski, не общий «вкус» | не чистка кода, не прод |
| Сверить проект со стандартами хаба | `/MA-revise-project` | тройка README/AGENTS/DESIGN (UI-чеклист в DESIGN, без указателей) + обязательные пути + список, что подтянуть; `llms.txt` — отдельным `/MA-seo-geo-audit` (учесть роут) | не выкат |
| Глубокая чистка модулей, «убери ИИ-стиль» | `/MA-product-pass` | модули читаются людьми; контракты не ломаются молча | не релиз |
| Задача в чате вроде готова | `/MA-signoff` | вердикт, оценка 1–10, ревью по типу темы, список доделок; чинить после «чини» | не выкат, не полная чистка продукта |
| Выкат на прод | `/MA-deploy` | одна **волна** (одна зона продукта) до прода: одно ревью темы → срез жира один раз → проверки **только этой волны** (чужие правки не блокеры) → упаковка волны → прод → обязательные пути. Смесь зон — несколько выкатов, стоп «какую волну сейчас» | не генеральная уборка; без списка путей не стартует; канон входа в `.env.local`; нет ролей — предложить создать + демо; созданное сверх демо убрать |
| SEO + видимость в ответах ИИ | `/MA-seo-geo-audit` | отчёт по поиску и ответам ИИ + черновик `llms.txt`; правки сайта — после «чини» | не выкат |
| Список команд | `/MA-help` | этот перечень и ссылка на карту | — |

Типичный путь: **сверка** (тройка файлов) → **идея** и/или **дизайн** → при шумном коде **полный прогон** → **приёмка** → **выкат** → **SEO+GEO** (в том числе живой `llms.txt`).

## Три упрощения (не смешивать)

| Где | Что | Зачем |
|-----|-----|--------|
| `/MA-idea-to-plan` | skill `ponytail` как **вкус** (не раздувать, не копировать текст) | фича не обрастает лишним |
| `/MA-product-pass` | `/simplify` + словарь **«убери ИИ-стиль»** | читать людям; контракты не ломать молча |
| `/MA-deploy` | `ponytail-review` **с автофиксом** **один раз на волну**; таблица `net` / `Lean already` — одна строка на тему, иначе стоп. Смесь зон — несколько выкатов. Прочитать skill ≠ прогнать | быстрый срез жира перед продом |

Не подменять одно другим. Жёсткий словарь анти-ИИ — **только** полный прогон.

## Хвост после завершённой работы

После **готово** (не на паузе «жду ответ»): блок **«Следующие задачи»** — ровно 4 пункта с копируемыми промптами, по правилу пользователя.

Статус процесса — полный: *Сейчас / Что происходит / Ждём / Обычно занимает / Что от вас* (`standards/00-operating-model.md`).
