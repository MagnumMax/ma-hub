# MA-help — команды Monster Automation

Покажи этот список коротко и предложи, какую команду запустить. Все команды начинаются с **MA-** — в чате набери `/MA` и выбери нужную.

Карта «когда что / что дальше»: `$MA_HUB_ROOT/templates/ma-command-map.md` (прочитай и следуй).

## Hub (источник правды)

Сначала найди корень **ma-hub**:
1. `~/.config/ma-hub/config` → `MA_HUB_ROOT`
2. иначе `~/ma-hub`, если есть `standards/`
3. иначе скажи запустить bootstrap: `git clone … && ./bootstrap/bootstrap.sh`

**Истина только в репозитории ma-hub** (`commands/`, `skills/`, `standards/`, `registry/`).  
`~/.cursor/commands/` и `~/.cursor/skills/` — кэш после `bootstrap` / `ma-hub-pull`.  
Внешние skills: ссылки в `registry/external-skills.md`, тела — с upstream через `install-external-skills.sh`.  
Стандарты: `$MA_HUB_ROOT/standards/` (VERSION в том файле).

## Когда что (одна фраза)

Идея или фича → `/MA-idea-to-plan`. Экран → `/MA-design-screen`. Сверка со стандартами → `/MA-revise-project`. Чистка кода / ИИ-шум → `/MA-product-pass`. Задача в чате вроде готова → `/MA-signoff`. На прод → `/MA-deploy`. Поиск и ответы ИИ → `/MA-seo-geo-audit`.

Типичный путь: сверка (если отстал) → идея и/или дизайн → при шумном коде полный прогон → приёмка → выкат → SEO.

## Ритуалы

| Команда | Когда вызывать |
|---------|----------------|
| `/MA-idea-to-plan` | Сырая идея / фича → уточнения → план → работа (не выкат) |
| `/MA-design-screen` | Админка, дашборд, лендинг, красивый фронт (не чистка кода) |
| `/MA-revise-project` | Сверить проект со стандартами ma-hub и подтянуть (тройка README/AGENTS/DESIGN + обязательные пути; `llms.txt` — через `/MA-seo-geo-audit`) |
| `/MA-product-pass` | Глубокая чистка (не релиз): модули → review + simplify «убери ИИ-стиль»; выкат через `/MA-deploy` |

## Приёмка

| Команда | Когда вызывать |
|---------|----------------|
| `/MA-signoff` | Конец задачи в чате: закрыта ли сполна, оценка 1–10, ревью по типу темы, список доделок. Не выкат: чинить только после «чини» |

## Релиз

| Команда | Когда вызывать |
|---------|----------------|
| `/MA-deploy` | Полный цикл перед продом: при смеси зон — волны (не один ком) → одно ревью выбранной темы → ponytail один раз на тему (таблица net, иначе стоп) → проверки этой темы (чужое не блокирует) → упаковка волны → push → CI → PR → prod → обязательные пути |

## Справка

| Команда | Когда вызывать |
|---------|----------------|
| `/MA-help` | Этот список |

**Во всех длинных `/MA-*`:** в паузе и в итоге сначала блок «Статус процесса» — *Сейчас / Что происходит / Ждём / Обычно занимает / Что от вас* (см. `standards/00-operating-model.md`). После **готово** — «Следующие задачи» (4 пункта), не на паузе «жду ответ».

**Ворота во всех ритуалах:** сначала тройка `README.md`, `AGENTS.md`, `DESIGN.md` (эталон `templates/project-canonical-pack.md`, разделы не пустые; существующий UI-чеклист вклеить в DESIGN в том же проходе, не указателем). Нет тройки → предложить создать. `llms.txt` пишет `/MA-seo-geo-audit` (файл или уже существующий роут), другие команды его не сочиняют. `/MA-revise-project` без тройки ставит её создание **и блок обязательных путей** первым пунктом, затем аудит для карты ИИ. `/MA-deploy` без списка путей в `AGENTS.md` не стартует: дописать в выкате или сначала сверка; полную сверку из выката не запускать. На проде вход из канона хаба (агент сам пишет `.env.local`); нет ролей — предложить создать + демо; созданное за прогон сверх демо убрать до письма клиенту.

**Три упрощения** (не смешивать) — в карте: идея = вкус ponytail; полный прогон = simplify «убери ИИ-стиль»; выкат = ponytail с автофиксом **один раз на выбранную тему**.

## Как пользоваться
1. Открой чат в нужном проекте
2. Напиши `/MA` и выбери команду
3. После команды опиши задачу одним-двумя предложениями
4. На новом ноутбуке: bootstrap из публичного ma-hub (см. README хаба)

**Заметка:** security / UX / guidelines — через навыки бандла или обычным текстом в чате.

Если пользователь не указал задачу — спроси одну фразу: что делаем. Напомни, что стандарты, команды и MA-skills живут в ma-hub и обновляются через `ma-hub-pull` / weekly.
